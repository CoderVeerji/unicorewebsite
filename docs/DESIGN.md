# Unicore Lubricants Design System

Strict typographic and color palette specification for Unicore Lubricants.
Two typography families: Instrument Serif for display headlines, section headers, card titles, and index numerals; Inter for UI and body text.
No Libre Caslon Text, no Newsreader, and no icon fonts.
Strict color palette limited to the 10 defined brand colors.
All box shadows forbidden except for the desktop Products navigation dropdown.
